# Playwright_Practice
Простой проект для практики использования Playwright с использованием паттерна POM

Ветки:
- Практика написания тестов с учетом паттерна POM (tests_with_POM)
- Практика покрытия тестов на 80-100% функционал в QA-Practice (tests_for_QA_Practice)
- Покрытие тест-кейсов написанные вручную для сайта https://demoblaze.com/ - Практика написания тест-кейсов, чек листов и автоматизация тестов (tests_real_practice)
